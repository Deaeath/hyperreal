# Hyperreal Studio

Turn a 3DXChat screenshot into a real-looking photo, or paint over anything and say what to change ("make my dress emerald green").

**Use it:** https://deaeath.github.io/hyperreal/

- Chat to edit, or tap a quick edit: Make it real, Cinematic, Portrait, Candid, Golden hour and more.
- Paint a rough selection with the brush (zoom in with the mouse wheel or a pinch). Only the area around it goes to Venice, and the result is blended back, so nothing outside the selection changes.
- Every edit is a version you can go back to, compare or download.
- Realism edits paint out the game's chat windows, menus and name tags.

It runs entirely in your browser on your own [Venice AI](https://venice.ai/settings/api) key, which goes only to api.venice.ai. Nothing is uploaded anywhere else. SBS members can use it with no key on the SBS desktop.

Everyone in your pictures must be an adult. Venice's own rules apply.
